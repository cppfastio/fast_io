# binfmt

Binary program representation of format strings (printf/fmt/strftime +
locale `name_fmt`/`postal_fmt`/`tel_*_fmt`), plus the RVA-based flat
locale container (`lcblob`).

See `spec.md` — the design is under review; `binfmt.h` and `compile.h`
are pre-review drafts pending the finalized tag/code layout.
